1. Executive Overview & System Philosophy

System Identity

NEW RAG SYSTEM (ROBUST) is the enterprise-grade Text-to-SQL platform built to resolve all historical failure modes of natural language database interfaces in high-compliance clinical domains:

Edge-Cases Addressed
  • Prompt Injection Attack Immunity: Prevents malicious manipulation of generated SQL by applying Layer 1 Abstract Syntax Tree (AST) parsing before execution.
  • Mutation & Rollback Failure Defense: Replaces transaction-rollback hacks with Layer 2 strict SELECT-Only Database Roles.
  • Temporal & Relative Date Precision: Uses deterministic Python CPU date math (`DateResolver`) for expressions like *"last quarter"*, *"Q1 2025"*.
  • Zero Schema Drift: Uses startup `SHA256(DDL)` hashing to re-index schema embeddings automatically when database structures change.
Technical Stack & Port Allocation
  • Port Allocation: Port 8002 (`http://127.0.0.1:8002`).
  • Backend Engine: FastAPI (Python 3.10+) with SQLAlchemy ORM and Server-Sent Events (SSE).
  • Embedding Model: `BAAI/bge-large-en-v1.5` (1024 dimensions) with FAISS FlatL2 index.
  • LLM Inference: Groq Cloud LPU platform (`llama-3.3-70b-versatile`).
  • UI Style: Sunset Orange GPT-style layout aligned with System 1 & 2.

5. Security & Boundary Enforcement

Zero Trust Defense
Layer 1 AST Parser (Code Gate)

Parses generated SQL using `sqlparse`/`sqlglot` Abstract Syntax Trees:

  • Must contain exactly 1 SQL statement.
  • Statement type must be strictly SELECT.
  • Rejects semicolon multi-statements (`SELECT ...; DROP TABLE ...`).
  • Rejects comment-hidden mutations (`SELECT * FROM surgeries -- DROP TABLE`).
Layer 2 Read-Only DB Role (Infrastructure Boundary)

Executes SQL against PostgreSQL/SQLite using read-only connection credentials:

  • Database user granted SELECT permissions ONLY.
  • Database rejects `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER` at OS kernel level.
  • Zero reliance on application rollback logic.
